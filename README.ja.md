# 👻 Moonlit Mirrors — ふたりのおばけのハロウィン恋愛パズル

**小さなおばけがふたり。動かす方向はひとつ。一緒に帰れる道を探そう。** Moonlit Mirrors は [Love Game](https://love-game.org/) のために作られた、オリジナルのハロウィンパズルです。青い Luna とピンクの Rose を、対になった部屋から導きます。壁と鏡を利用して足並みをそろえると、やさしい再会が待っています。

**[今すぐ遊ぶ](https://halloween-mirror-hearts.crazy3d.org/)** · [ハロウィンゲーム集](https://github.com/AshinTop/halloween-games) · [埋め込みガイド](EMBEDDING.md) · [設計ノート](DESIGN.md)

## ふたつの心のためのパズル 🎃

- **5×5 の部屋が 12 組**。全問に検証済みの解答と正確な最少手数があります。
- 鏡の動き、共有の鍵、後半で登場する横移動の切り替え。
- 無制限の取り消し、やり直し、部屋選択、現在の状態から解くヒント。
- オリジナル SVG のおばけ、任意の音、ローカル記録、ハグとキスのクリア演出。

## 部屋の仕組み

方向を入力すると、ふたりが同時に動こうとします。鏡モードでは上下は同じ方向、左右は逆方向です。片方が壁にぶつかると、そのおばけだけが止まり、もう片方は動けます。この差を使って位置を合わせましょう。

**ふたりが同時に、それぞれのハートの扉に立つ**とクリアです。鍵のある部屋では先に鍵を取る必要があります。部屋 4 からは鍵の仕掛けが登場し、取った一手が終わってから両側の鍵付きゲートが開きます。鍵を取る途中で、まだ閉じたゲートを通ることはできません。

部屋 7 からの**位相切り替え**では、横方向を鏡の動きと同方向の動きに切り替えます。切り替えにも 1 手を使います。後半の最短ルートには、この操作が含まれます。

正確な最少手数なら星 3 つ、目標の 1.5 倍を切り上げた手数以内なら 2 つ、それ以外のクリアは 1 つです。時間切れや強制的な失敗はありません。ヒントを使っても星は減りません。

## 操作

| 操作 | マウス・タッチ | キーボード |
|---|---|---|
| ふたりを動かす | 方向ボタン、またはおばけの隣のマス | 矢印 / W A S D |
| 取り消し | ボタン | Z |
| 次の解答手順 | ヒント | H |
| 位相切り替え | 解放後のボタン | ボタン外で Space |
| やり直し・部屋選択 | 画面の操作欄 | Tab と Enter |

Rose の隣を押した場合は、彼女が画面上で動く方向に入力を変換します。小さな埋め込み画面では方向ボタンが分かりやすい操作方法です。

ヒントは**現在のふたりの位置、鍵、位相**から、残りの最短ルートを探して次の一手を示します。その状態から解けない場合は、取り消しややり直しを使ってください。

## たどり着いた先の再会

クリアすると、星をつけた Luna とリボンの Rose がふわりと近づき、腕を回してハグ。小さなキスとハートの吹き出しのあと、寄り添う姿で落ち着きます。演出は約 2.8 秒で、次の部屋や閉じるボタンはすぐに使えます。動きを減らす設定では静かなハグの絵になります。ルール、手数、星は変わりません。

最少クリア手数と設定はブラウザーに保存します。再読み込みでは選んだ部屋を最初から始め、途中の位置は復元しません。[部屋 9 のリンク](https://halloween-mirror-hearts.crazy3d.org/#room=9) は開始する部屋を共有するもので、プレイの再生ではありません。

## よくある質問

**オンライン協力プレイですか？** ひとつの端末で遊ぶパズルです。ひとりでも、隣の人と相談しながらでも楽しめます。

**片方だけ動いたのはなぜ？** それぞれの部屋の壁が別々に判定されるためです。

**試行錯誤やヒントで不利になりますか？** 取り消しは無制限で、ヒントによる星の減点もありません。星は完成時の手数で決まります。

## 自分のサイトに埋め込む

```html
<iframe src="https://halloween-mirror-hearts.crazy3d.org/"
  title="Moonlit Mirrors"
  style="display:block;width:100%;height:521px;border:0"
  allow="fullscreen" allowfullscreen></iframe>
```

想定する親サイトの枠は、833×521 のデスクトップ、356×280 と 326×280 の Love Game 小型枠、390×650 の縦長、844×340 の横長です。小さい枠では方向ボタンを使い、余裕があれば高さを増やしてください。小型ダイアログも操作ボタンを保ち、必要に応じて内部をスクロールできます。

公開版は、この GitHub リポジトリと連携して Cloudflare にデプロイされています。iframe に高さを指定し、親サイトのツールバー用の領域も確保してください。全画面ボタンは親サイト側で用意できます。詳細は [EMBEDDING.md](EMBEDDING.md) を参照してください。

## ローカルで実行・確認する

```sh
python3 -m http.server 4173
```

リポジトリのルートでサーバーを起動し、[http://localhost:4173/](http://localhost:4173/) を開きます。静的なゲームなので、ビルドや依存パッケージのインストールは不要です。`file://` では ES モジュールが読み込めない場合があるため、HTTP(S) を使用してください。テストには Node.js が必要です。

```sh
npm test
```

**12 件のテスト**で、正確な探索距離、全問の解答、鏡方向、別々の壁判定、鍵の開く時点、切り替えの手数、状態変更後のヒント、取り消し、星、状態検証を確認します。

ゲームのソースはアカウント、外部 API、広告 SDK、外部素材 CDN を必要としません。記録はブラウザー内に保存され、クラウド同期はありません。Cloudflare が独自のホスティング用スクリプトやリクエストログを追加する場合があります。任意の合成音声はブラウザーの再生許可に従います。
